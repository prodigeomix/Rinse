# Security Policy

## Supported Versions

Rinse receives active maintenance on the latest released version for Turtle WoW Patch 1.18.1 and Vanilla 1.12.1.

| Version | Supported          |
| ------- | ------------------ |
| 2.8.x   | :white_check_mark: |
| < 2.8.0 | :x:                |

---

## Reporting a Vulnerability or Critical Defect

If you discover a client-crashing memory fault, infinite loop, or severe execution defect in Rinse, please report it promptly:

1. **GitHub Issues**: Open an issue labeled `bug` with details of the defect, reproduction steps, and client environment.
2. **Crash Dumps**: When reporting client crashes, include the relevant `nampower_debug.log`, `WoWCombatLog.txt`, or Windows Event Viewer error details.

We aim to review all reports within 48 hours.
